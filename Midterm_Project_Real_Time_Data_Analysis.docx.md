**MIDTERM PROJECT**

*Real-Time Data Collection and Stream Processing System*

Coverage: Weeks 1–4 — Introduction to Real-Time Data Analysis with Python; Python Fundamentals for Data Streaming; Data Acquisition and Stream Processing; Real-Time Data Processing with Pandas and NumPy.

| Project Element | Requirement |
| :---- | :---- |
| Goal | Develop a Python-based system that continuously acquires incoming data, processes the stream, calculates real-time statistics, and detects basic events or anomalies. |
| Suggested domains | IoT/sensor monitoring, transportation, finance, weather, smart campus, website activity, logistics, or another suitable streaming scenario. |
| Technologies | Python, Pandas, NumPy. Data may come from a generated stream, CSV/JSON source, API, or another accessible source. |

# **Required Tasks**

* Define a realistic real-time data scenario and describe the source, schema, frequency, and meaning of incoming records.  
* Create or obtain timestamped data and implement a Python stream/data generator if a live source is unavailable.  
* Implement incremental data acquisition so that records are processed as they arrive.  
* Use Pandas and NumPy for cleaning, transformation, aggregation, and real-time analysis.  
* Calculate at least three real-time indicators, such as moving average, event count, rate, minimum/maximum, or rolling standard deviation.  
* Implement at least one rule-based event or anomaly detector.  
* Display continuously updated results using console output, tables, or visualization.  
* Store processed results for later analysis and reproducibility.

# **Deliverables**

* Python source code organized into logical modules/functions.  
* Input dataset or reproducible data generator.  
* README with installation and execution instructions.  
* Technical report of approximately 5–7 pages.  
* Demonstration of incremental data acquisition and processing.  
* At least one table and one visualization of results.

# **Assessment Focus**

The project should demonstrate practical knowledge of Python for streaming data, data acquisition, incremental processing, and real-time analysis using Pandas and NumPy.
